Machai MCP Server

Machai MCP Server is a server implementation for the Model Context Protocol (MCP) built with the Machai AI framework. It integrates GenAI tools and supports HTTP and standard-input/standard-output (STDIO) interfaces for AI-powered tool execution and orchestration. The server does not publish tools of its own; applications provide functional-tool and prompt libraries to expose their capabilities through MCP.

Machai MCP Server supports all types of project files, including source code, documentation, project site content, and other relevant files. A configured project directory is passed to invoked tools so those tools can operate on the project content appropriate to their implementation.

Architecture and operation

The runtime loads configured function tools, optionally filters them by the enabled-tools setting, and registers their MCP capabilities. GenAI adapters translate tool parameter metadata to JSON Schema, create transport-specific MCP specifications, and invoke tools with request arguments, the project directory, configurator, and, where available, the active session identifier. Prompt adapters similarly register prompts and turn function results into MCP prompt messages.

The command-line entry point selects the STDIO server by default. Supplying a port starts the stateless HTTP server, while the session option selects the streamable HTTP server. Shared server infrastructure owns project and tool-filtering configuration; the HTTP base class configures Jetty and its MCP transport servlet.

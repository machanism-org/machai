Machai MCP Server

Machai MCP Server is a server implementation for the Model Context Protocol (MCP) using the Machai AI framework. It provides integration with GenAI tools and supports both HTTP and STDIO interfaces for AI-powered tool execution and orchestration. The project does not include its own tools for publication and requires additional libraries that implement functional tools and prompts. The project supports all types of project files, including source code, documentation, project-site content, and other relevant files.

Purpose

The server discovers Machai function tools through the configured tool-loading mechanism and exposes them as MCP tool specifications and synchronous call handlers. HTTP implementations can also expose prompts and resources supplied by loaded providers. This makes the module suitable for local process integrations and remote MCP deployments backed by Jetty, while keeping transport handling separate from tool implementation.

Package Structure

The {@link org.machanism.machai.mcp.server} package contains the executable entry point, shared server abstractions, transport-specific implementations, and adapters that convert Machai tool metadata into MCP specifications. Its public API is intended to be used by applications that supply compatible Machai tool providers rather than by applications that define tools directly in this module.

  • Server entry point: {@link org.machanism.machai.mcp.server.McpServer} parses command-line options, loads configuration, and starts the appropriate mode. Without a port it starts STDIO; with a port it starts HTTP. The {@code --session} option selects streamable HTTP instead of stateless HTTP.
  • Common server base: {@link org.machanism.machai.mcp.server.AbstractMcpServer} defines shared server metadata, project-directory handling, lifecycle hooks, and the tool-specification builder contract.
  • HTTP infrastructure: {@link org.machanism.machai.mcp.server.AbstractHttpMcpServer} configures the Jetty server, connector, servlet context, and HTTP transport servlet used by remote deployments.
  • HTTP server modes: {@link org.machanism.machai.mcp.server.HttpStatelessMcpServer} provides stateless synchronous HTTP handling, while {@link org.machanism.machai.mcp.server.HttpStreamableMcpServer} provides streamable, session-oriented HTTP handling. Their corresponding adapters are {@link org.machanism.machai.mcp.server.HttpStatelessGenericGenaiAdapter} and {@link org.machanism.machai.mcp.server.HttpStreamableGenericGenaiAdapter}.
  • STDIO server mode: {@link org.machanism.machai.mcp.server.StdioMcpServer} exposes MCP over standard input and output, using {@link org.machanism.machai.mcp.server.StdioGenaiAdapter} for process-based clients.
  • Tool integration: {@link org.machanism.machai.mcp.server.GenericGenaiAdapter} registers Machai GenAI tools, builds JSON schemas from parameter descriptors, routes MCP calls to Machai {@code ToolFunction} instances, adds session context when available, and serializes results for MCP clients.

Runtime Behavior

During startup, the selected server initializes the configured tool loader and applies the available Machai tools through {@link org.machanism.machai.mcp.server.GenericGenaiAdapter}. Each parameter descriptor becomes a property in an MCP-compatible JSON schema, including requiredness, type, description, and a default where applicable. The adapters also translate supported prompt and resource definitions into their corresponding MCP specifications. On invocation, an adapter converts request arguments to JSON, adds the MCP session identifier when an exchange provides one, invokes the underlying function with the project directory and configuration, and returns its value as text or serialized JSON. Exceptions produce MCP tool results marked as errors.

Usage

Start the application through {@link org.machanism.machai.mcp.server.McpServer}. Supported command-line options are:

  • {@code -h}, {@code --help}: display command-line help.
  • {@code -d}, {@code --projectDir}: specify the project directory used by loaded tools.
  • {@code -n}, {@code --name}: set the MCP server name.
  • {@code -c}, {@code --config}: select the Machai configuration name.
  • {@code -v}, {@code --version}: set the MCP server version.
  • {@code -p}, {@code --port}: run as an HTTP MCP server on the given port.
  • {@code -s}, {@code --session}: use streamable HTTP server mode when running over HTTP.

If no port is provided, the server uses STDIO mode. If a port is provided, the server uses HTTP mode; stateless HTTP is the default and streamable HTTP is enabled with {@code --session}.

Extensibility

The implementation separates transport concerns from tool registration. New transport modes can extend {@link org.machanism.machai.mcp.server.AbstractMcpServer} or {@link org.machanism.machai.mcp.server.AbstractHttpMcpServer} and provide a suitable tool-specification builder and adapter. Additional GenAI tools and prompts can be supplied through Machai's tool-loading mechanism and are exposed to MCP clients without changing the server entry point. Implementations should preserve the MCP schema and error-result behavior established by the supplied adapters.

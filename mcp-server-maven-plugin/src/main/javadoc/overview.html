MCP Server Maven Plugin

Maven plugin for launching the Machai MCP Server directly from a Maven build, exposing Machai AI tools through the Model Context Protocol over HTTP for local development, testing, demonstrations, and integration workflows without requiring a separate launcher.

Purpose and behavior

This project provides aggregator goals that start an HTTP MCP server for the current Maven reactor. Each goal uses the active Maven project's name and version as server identity, uses its base directory as the server project directory, applies optional runtime parameters and Maven settings credentials, registers the configured Machai tools, and binds the server to the required port. The plugin is useful when an MCP-compatible client needs project-aware tools during a build or development session.

The two goals differ only in HTTP transport: stateless handles requests without persistent session state, while streamable supports streamable HTTP interactions. Both goals are marked as aggregator goals and therefore are intended to run once for a multi-module build rather than once per module.

Goals and configuration

mcp-server:stateless
Starts an HttpStatelessMcpServer using the Maven project metadata, project directory, configured port, and resolved tool configuration.
mcp-server:streamable
Starts an HttpStreamableMcpServer using the same project metadata and configuration, with streamable HTTP transport.

The principal parameters are:

  • port / mcp.port — required TCP port for the HTTP server.
  • basedir — required Maven module base directory, normally resolved from ${basedir} and passed as the server project directory.
  • project — read-only current Maven project, normally resolved from ${project} and used for server name and version.
  • params — optional map of runtime parameters. A parameter is applied as a system property only when that property is not already set.
  • serverId — optional Maven settings.xml server id. Its username, password, and custom configuration values are resolved for the MCP configuration.
  • settings — read-only Maven settings, normally resolved from ${settings} for credential lookup.

Typical usage

From the Maven project directory, start one goal and provide the required port:

  • mvn org.machanism.machai:mcp-server-maven-plugin:stateless -Dmcp.port=8080
  • mvn org.machanism.machai:mcp-server-maven-plugin:streamable -Dmcp.port=8080

Add the plugin to pom.xml when a shorter goal invocation is preferred. Configure any params and serverId values there, start the selected goal, and connect an MCP-compatible client to the resulting HTTP endpoint. Stop the running process through the available server-management tool or by terminating Maven.

Package structure

org.machanism.machai.mcp.maven

This package contains the shared Mojo base class and the two concrete aggregator goals. The AbstractMCPServerMojo centralizes Maven parameter injection, system-property handling, and credential/configuration resolution. HttpStatelessServerMojo creates and starts the stateless server, while HttpStreamableMcpServerMojo creates and starts the streamable server. Failures during startup are reported as MojoExecutionException instances.

org.machanism.machai.mcp.maven.tools

This package contains the MCP function-tool integration for server operations. Its MCPServerTools exposes the stop_mcp_server function, which accepts an optional integer exit code, records the shutdown request, and initiates server termination. The tool is supported for McpServer and allows a connected client to stop a server launched by the plugin.

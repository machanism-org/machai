MCP Server Maven Plugin

Maven plugin for launching the Machai MCP Server directly from a Maven build, exposing Machai AI tools through the Model Context Protocol over HTTP for local development, testing, demonstrations, and integration workflows without requiring a separate launcher.

The plugin supports the complete Maven project context needed by the server, including source code, documentation, project-site content, and other files available beneath the Maven project's base directory. This context lets project-aware MCP tools operate against the same project that invoked the build.

Purpose and behavior

This project supplies two aggregator goals that create and start an HTTP MCP server for the current Maven reactor. Each goal applies optional runtime parameters, loads the MCP configuration file, sets the server project directory to the Maven module base directory, uses the active project's name and version as server metadata, registers the configured Machai tools, and binds the server to the required port. An MCP-compatible client can therefore use project-aware tools during a build or development session.

The goals differ by transport: stateless starts an HttpStatelessMcpServer, whereas streamable starts an HttpStreamableMcpServer. Both are aggregator goals, so a multi-module build starts one server for the reactor rather than one server per module. Startup and configuration failures are reported to Maven as MojoExecutionException failures.

Goals and configuration

mcp-server:stateless
Starts a stateless HTTP MCP server after applying the current project's metadata, base directory, port, loaded configuration, and registered tools.
mcp-server:streamable
Starts a streamable HTTP MCP server with the same Maven project context and configuration.

The principal Mojo parameters are:

  • port / mcp.port — required TCP port on which the selected HTTP server listens.
  • configFile / mcp.config — optional Maven-injected configuration file reference used to load MCP server and tool settings; server startup requires a usable configuration file.
  • basedir — required Maven module base directory, normally resolved from ${basedir} and passed as the server project directory.
  • project — read-only current Maven project, normally resolved from ${project} and used for server name and version.
  • params — optional map of values copied to system properties. Existing system properties are preserved and are not overwritten.

Typical usage

From the Maven project directory, start one goal and provide the required port and configuration:

  • mvn org.machanism.machai:mcp-server-maven-plugin:stateless -Dmcp.port=8080 -Dmcp.config=/path/to/mcp.properties
  • mvn org.machanism.machai:mcp-server-maven-plugin:streamable -Dmcp.port=8080 -Dmcp.config=/path/to/mcp.properties

Alternatively, declare the plugin in pom.xml and configure its parameters there. Select the transport expected by the MCP client, start the goal from the desired reactor root, connect the client to the resulting HTTP endpoint, and use the registered tools. The stop_mcp_server function initiates a delayed shutdown and accepts an optional exit_code, which defaults to 0.

Package structure

org.machanism.machai.mcp.maven

This package provides the shared Mojo base class and the two concrete aggregator goals. The AbstractMCPServerMojo receives Maven project, directory, port, configuration-file, and parameter values, applies parameters without replacing existing system properties, and loads a PropertiesConfigurator. HttpStatelessServerMojo creates and starts the stateless server, while HttpStreamableMcpServerMojo creates and starts the streamable server. This package is the plugin's Maven integration layer.

org.machanism.machai.mcp.maven.tools

This package supplies the server-lifecycle function tool integration. The MCPServerTools class is supported for McpServer and exposes stop_mcp_server. The function accepts an optional integer exit code, returns a shutdown confirmation immediately, records usage after a short delay, and then terminates the server process.

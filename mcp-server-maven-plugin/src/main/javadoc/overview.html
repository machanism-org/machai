MCP Server Maven Plugin

The MCP Server Maven Plugin integrates a Machai Model Context Protocol (MCP) server into a Maven build. Its aggregator goals start a single stateless or streamable HTTP server for a Maven reactor, enabling MCP clients to use the configured Machai AI tools without a separate launcher. This supports local development, repeatable integration tests, demonstrations, and build-driven automation.

During startup, the plugin derives the current project's name, version, and base directory; loads the configured PropertiesConfigurator; applies Maven parameters without replacing existing system properties; and registers the configured Machai AI tools. The resulting MCP server supports all types of project files, including source code, documentation, project-site content, and other relevant files exposed through its configured tools.

Architecture

The principal Maven package supplies an abstract Mojo with shared configuration and lifecycle behavior, plus concrete goals for stateless and streamable HTTP transports. Its tools package provides functions that MCP clients can invoke to manage server operations during a build.

Packages

org.machanism.machai.mcp.maven
Maven plugin Mojos for configuring and starting MCP servers, including stateless and streamable HTTP variants, with shared environment-variable and credential configuration.
org.machanism.machai.mcp.maven.tools
Function tools and supporting utilities for controlling, configuring, and managing the MCP server lifecycle while Maven builds execute.

Usage

Configure the plugin with the desired transport and Machai tool configuration, then invoke the appropriate Maven goal. In a multi-module build, the aggregator goal starts one server for the complete reactor, making the configured project context and tools available to connected MCP clients.

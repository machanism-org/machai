MCP Server Maven Plugin

The MCP Server Maven Plugin integrates a Machai Model Context Protocol (MCP) server into a Maven build through aggregator goals for stateless and streamable HTTP transports. It uses the current project's name, version, and base directory; loads the configured properties configurator; applies Maven parameters without overriding existing system properties; registers configured Machai AI tools; and starts the selected server. The plugin exposes those tools to MCP clients without a separate launcher, supporting local development, repeatable integration tests, demonstrations, and build-driven automation while starting one server for a multi-module reactor.

Purpose and operation

Each goal applies configured parameters as system properties without overwriting properties that are already set, loads the MCP configuration, associates the server with the Maven project's name, version, and base directory, registers the configured tools, and starts an HTTP endpoint on the requested port. The project context includes source code, documentation, site content, and other files beneath the Maven project directory, allowing project-aware tools to work on the same project that invoked Maven.

Both goals are aggregators, so a reactor invocation starts one server for the build rather than one per module. Configuration or startup errors are reported to Maven as MojoExecutionException failures.

Goals and parameters

mcp-server:stateless
Creates and starts an HttpStatelessMcpServer.
mcp-server:streamable
Creates and starts an HttpStreamableMcpServer.
  • port (mcp.port): required HTTP listening port.
  • configFile (mcp.config): optional Maven parameter whose readable file is loaded by the MCP configuration provider when the goal executes.
  • basedir: required Maven module base directory, normally ${basedir}, used as the server project directory.
  • project: read-only current MavenProject, normally ${project}, supplying server name and version.
  • params: optional map copied to system properties only when those properties do not already exist.

Usage

From the project or reactor directory, provide a port and configuration file:

  • mvn org.machanism.machai:mcp-server-maven-plugin:stateless -Dmcp.port=8080 -Dmcp.config=/path/to/mcp.properties
  • mvn org.machanism.machai:mcp-server-maven-plugin:streamable -Dmcp.port=8080 -Dmcp.config=/path/to/mcp.properties

Select the transport expected by the MCP client, connect it to the resulting HTTP endpoint, and use the registered tools. The stop-mcp-server function initiates delayed shutdown and accepts an optional exit-code, defaulting to 0.

Package overview

org.machanism.machai.mcp.maven

This package provides the Mojos and shared configuration utilities that manage an MCP server during a Maven build. It contains one abstract base Mojo and two concrete, aggregator transport goals. Use this package when a Maven invocation must configure and expose a project-aware MCP server rather than starting a server with a separate runtime command.

  • AbstractMCPServerMojo supplies the Maven base directory, current MavenProject, required port, optional parameter map, and configuration-file handling. It copies parameter-map entries to previously unset JVM system properties and loads the PropertiesConfigurator used to configure server tools.
  • HttpStatelessServerMojo implements the stateless goal. It creates an HttpStatelessMcpServer, assigns the Maven project name and version, project directory, configured tools, and port, then starts it.
  • HttpStreamableMcpServerMojo implements the streamable goal with the same setup sequence for an HttpStreamableMcpServer.

The concrete Mojos inherit common behavior so both transports receive equivalent project metadata and configuration. Failures while loading configuration or starting either server are surfaced to Maven as MojoExecutionException failures.

org.machanism.machai.mcp.maven.tools

This supporting package contains function tools for MCP server operations. Its MCPServerTools implementation exposes lifecycle control through FunctionTools and is supported for McpServer. The stop-mcp-server function accepts an optional exit-code (default 0), immediately confirms the request, waits for a short grace period on a background thread, records usage statistics, and exits the server process with the requested code. Invoke it from an MCP client after server work is complete.

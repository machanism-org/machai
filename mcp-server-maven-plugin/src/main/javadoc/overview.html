MCP Server Maven Plugin

The MCP Server Maven Plugin integrates a Machai Model Context Protocol (MCP) server into a Maven build. It provides stateless and streamable HTTP goals that expose Machai AI tools using the current project's metadata and configuration. The plugin supports local development, repeatable integration tests, demonstrations, and build-driven automation without requiring a separate launcher, and its aggregator goals support multi-module builds.

Purpose and operation

Each goal applies configured parameters as system properties without overwriting properties that are already set, loads the MCP configuration, associates the server with the Maven project's name, version, and base directory, registers the configured tools, and starts an HTTP endpoint on the requested port. The project context includes source code, documentation, site content, and other files beneath the Maven project directory, allowing project-aware tools to work on the same project that invoked Maven.

Both goals are aggregators, so a reactor invocation starts one server for the build rather than one per module. Configuration or startup errors are reported to Maven as MojoExecutionException failures.

Goals and parameters

mcp-server:stateless
Creates and starts an HttpStatelessMcpServer.
mcp-server:streamable
Creates and starts an HttpStreamableMcpServer.
  • port (mcp.port): required HTTP listening port.
  • configFile (mcp.config): optional Maven parameter whose readable file is loaded by the MCP configuration provider when the goal executes.
  • basedir: required Maven module base directory, normally ${basedir}, used as the server project directory.
  • project: read-only current MavenProject, normally ${project}, supplying server name and version.
  • params: optional map copied to system properties only when those properties do not already exist.

Usage

From the project or reactor directory, provide a port and configuration file:

  • mvn org.machanism.machai:mcp-server-maven-plugin:stateless -Dmcp.port=8080 -Dmcp.config=/path/to/mcp.properties
  • mvn org.machanism.machai:mcp-server-maven-plugin:streamable -Dmcp.port=8080 -Dmcp.config=/path/to/mcp.properties

Select the transport expected by the MCP client, connect it to the resulting HTTP endpoint, and use the registered tools. The stop_mcp_server function initiates delayed shutdown and accepts an optional exit_code, defaulting to 0.

Package overview

org.machanism.machai.mcp.maven

This package is the Maven integration layer. AbstractMCPServerMojo centralizes project, directory, port, parameter, and configuration handling. HttpStatelessServerMojo and HttpStreamableMcpServerMojo extend it as aggregator goals and start their respective HTTP server implementations after configuring the project directory, tools, metadata, and port.

org.machanism.machai.mcp.maven.tools

MCPServerTools implements FunctionTools and is supported for McpServer. Its stop_mcp_server function immediately confirms the request, waits briefly, records usage statistics, and exits the server process with the requested code.

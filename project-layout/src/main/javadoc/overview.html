Project Layout

Project Layout is a utility library for describing and working with conventional project directory layouts consistently. It is intended for build tooling and plugins that need to locate well-known folders reliably across different projects. It supports all types of project files, including source code, documentation, project site content, and other relevant files.

Architecture and usage

The API detects Maven, Gradle, JavaScript/TypeScript, and Python project metadata and selects an appropriate layout implementation. Each layout exposes root-relative source, test, documentation, and module locations, while a default filesystem-based layout handles projects without a recognized descriptor. The project package coordinates detection and recursive module processing; callers extend its processor to apply work to each discovered project.

Typical consumers start with ProjectLayoutManager to obtain a ProjectLayout, or extend ProjectProcessor when the same operation must be performed for a project and its child modules.

Packages

org.machanism.machai.project
Coordinates project-layout detection and recursive processing. Its manager chooses a layout from recognized build descriptors, and its processor provides the extension point for applying an operation to projects and their modules.
org.machanism.machai.project.layout
Defines the project-layout abstraction, concrete Maven, Gradle, JavaScript/TypeScript, Python, and fallback layouts, plus Maven descriptor reading support. Layouts report conventional root-relative source, test, documentation, identity, and module paths.

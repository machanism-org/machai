GenAI Client

GenAI Client is a Java library designed for seamless integration with Generative AI providers. It offers foundational prompt management and embedding capabilities, enabling AI-powered features across Machanism modules. The library simplifies interactions with AI services and supports semantic search, automated content generation, and intelligent project assembly within the Machanism ecosystem.

GenAI Client supports all types of project files, including source code, documentation, project site content, and other relevant files. Applications can expose project-specific capabilities as annotated tools, prompts, and resources; configure a provider; submit generation or embedding requests; and incorporate the results into their project workflows.

Architecture

The provider package defines the provider-neutral conversation and embedding contracts, shared request-building behavior, delegation support, type conversion, and invocation logging. The implementation package adapts those contracts to OpenAI and Anthropic, routes CodeMie-authenticated requests to a compatible backend, supports local YAML-driven tool execution, and supplies a disabled provider. The manager package creates configured providers from provider-and-model identifiers and records token usage. The tools package supplies annotations, descriptors, service-based discovery, callable-tool contracts, roles, and exception types for making host Java methods available to providers.

A typical integration resolves a provider through the manager, initializes it with a model and configuration, registers annotated function-tool objects, adds instructions, prompts, or resources, and performs a request. Concrete providers isolate vendor SDKs and backend configuration while the common contracts keep the application-facing flow consistent. Providers retain request state until cleared, so a reusable provider should be cleared before it is used for an unrelated conversation.

Packages

org.machanism.machai.ai.manager
Resolves configured generative-AI and embedding providers from provider-and-model identifiers, and collects input, cached-input, and output token-usage records by model identifier.
org.machanism.machai.ai.provider
Defines provider-neutral generation and embedding contracts, reusable provider behavior, delegation support, type conversion, and logging for prompts, tools, resources, web search, and MCP server configuration.
org.machanism.machai.ai.provider.impl
Implements OpenAI and Anthropic integrations; CodeMie authentication and model-prefix routing; local YAML-driven function-tool execution; and a no-operation provider for intentionally disabled AI work.
org.machanism.machai.ai.tools
Provides annotations and metadata for declaring Java tools, prompts, resources, and parameters, along with service-based discovery, callable-tool contracts, roles, and structured error types.

Using the API

Start with the provider and tools package summaries to select a provider contract and declare application capabilities. Use the manager package when the provider must be selected dynamically from configuration. Concrete provider documentation describes backend-specific credentials, endpoints, model options, supported capabilities, and request lifecycle details. Use an embedding provider for vector-generation workflows, and register function-tool implementations when a model or local tool workflow needs access to project capabilities.

GenAI Client

GenAI Client is a Java library for integrating Generative AI providers with Machai applications. It provides foundational prompt management, tool and resource registration, embedding generation, provider selection, and usage accounting so that applications can add semantic search, automated content generation, and intelligent project assembly without coupling their core logic to a particular AI SDK.

GenAI Client supports all types of project files, including source code, documentation, project site content, and other relevant files. Applications expose project-specific capabilities as annotated tools, prompts, and resources; configure a provider; submit prompts or embedding requests; and use the resulting content in their project workflows.

Architecture

The provider package defines provider-neutral conversation and embedding contracts and shared request-building behavior. Its implementation subpackage adapts those contracts to OpenAI, Anthropic, CodeMie, local YAML-driven tools, or a disabled provider. The manager package resolves providers from provider-and-model identifiers and records token usage. The tools package supplies the annotations, descriptors, discovery mechanism, and exception types that make host Java methods available to providers.

A typical integration resolves a provider through the manager, initializes it with a model and configuration, registers any annotated function-tool objects, adds prompts or instructions, and performs a request. Provider implementations isolate vendor SDKs, while the common contracts allow the same application-facing flow to work across supported backends.

Packages

org.machanism.machai.ai.manager
Resolves configured generative-AI and embedding providers and collects token-usage records by model identifier.
org.machanism.machai.ai.provider
Defines provider-neutral contracts, reusable provider behavior, delegation support, type conversion, and invocation logging.
org.machanism.machai.ai.provider.impl
Implements integrations for OpenAI, Anthropic, and CodeMie, plus local tool execution and a no-operation provider.
org.machanism.machai.ai.tools
Provides annotations, metadata, discovery, callable-tool contracts, and error types for exposing Java capabilities to AI providers.

Using the API

Start with the provider and tools package summaries to select the appropriate provider contract and declare application capabilities. Use the manager package when a provider must be selected dynamically from configuration. Concrete provider documentation details backend-specific credentials, endpoints, model options, and supported capabilities.

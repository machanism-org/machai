GW Maven Plugin API

Ghostwriter Maven Plugin is an advanced documentation automation tool for Java projects. It scans, analyzes, and assembles project documentation by applying embedded guidance tags and AI-powered synthesis, helping Maven builds maintain consistent, current documentation across modules.

The plugin supports all types of project files, including source code, documentation, project site content, and other relevant files. Its Maven goals configure Ghostwriter from project and Maven settings, then execute either guidance-driven processing or an explicitly selected act over the requested project tree.

Architecture and usage

The Maven integration package supplies common goal infrastructure for configuration, project traversal, exclusions, provider credentials, and reporting. Aggregator goals can process a project tree and its modules; per-module goals instead rely on Maven reactor scheduling. The tools package supplies controlled class discovery and reflection metadata to Ghostwriter workflows after a Maven project has been registered.

Run the appropriate Maven goal to scan embedded guidance comments or to execute an act. Configure paths, instructions, exclusions, and provider settings through the documented mojo parameters; use the per-module goals when Maven should schedule selected reactor modules individually.

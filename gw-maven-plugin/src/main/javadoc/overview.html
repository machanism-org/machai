GW Maven Plugin

GW Maven Plugin, the Ghostwriter Maven Plugin, is an advanced documentation automation tool for Java projects. It automatically scans, analyzes, and assembles project documentation using embedded guidance tags and AI-powered synthesis. The plugin streamlines the creation and maintenance of high-quality, consistent documentation, ensuring best practices and up-to-date information across all modules.

The plugin can process every relevant project file, including source code, documentation, project site content, and other repository files. Guidance stays beside the content it governs, allowing documentation workflows to be reviewed in version control and invoked from a Maven build.

Package overview

The org.machanism.machai.gw.maven package contains the Maven mojos that connect Maven project and reactor state to Ghostwriter processors. AbstractGWMojo centralizes model, scan-path, instruction, exclusion, settings-server, optional configuration-file, and additional parameter handling. It also registers project class-introspection tools when a Maven project is available. The concrete mojos provide aggregator and per-module variants for guidance processing and act execution.

The related org.machanism.machai.gw.maven.tools package exposes controlled classpath inspection to Ghostwriter workflows. ClassInfoHolder builds a class loader from Maven compile and output paths, discovers loadable classes, and records their origin and dependency coordinates. ClassFunctionalTools exposes class-name pattern matching and structured reflection metadata, including modifiers, inheritance, interfaces, fields, constructors, methods, annotations, source paths, and class locations.

Goals and execution models

gw:gw
Aggregator guidance goal. It may run without a pom.xml, coordinates multi-module traversal itself, processes submodules before parent modules, and can use Maven parallelism.
gw:gw-per-module
Per-module guidance goal. It runs in the Maven reactor and processes modules according to the standard reactor dependency order.
gw:act
Aggregator act goal. It executes an inline prompt or named act, can prompt interactively when no act is configured, processes modules in reverse order, and may run without a local POM.
gw:act-per-module
Per-module act goal. It participates in normal reactor execution and uses the execution-root context while applying an action to the selected files.

Execution flow

  1. Maven supplies project, session, reactor, and settings context when the selected goal requires it.
  2. The common mojo reads credentials and provider properties from the selected Maven settings.xml server, or loads the optional Ghostwriter properties file when no server is selected.
  3. The goal resolves the model, scan path, instructions, exclusions, configuration, and act or guidance request.
  4. A GuidanceProcessor or ActProcessor scans the selected files and applies the workflow. Class tools are registered when project metadata is available.
  5. Aggregator goals coordinate module traversal; per-module goals allow Maven's reactor to order executions. Usage statistics are recorded after processing.

Configuration and usage

Common properties are gw.model for provider/model selection, gw.path for the scan root, gw.instructions for additional instructions, gw.excludes for skipped paths, and gw.config for an optional properties file. Act goals also accept gw.act for prompt text or an act name and gw.acts for an act directory or URL. genai.serverId selects the Maven settings server whose credentials and custom XML properties are forwarded to the provider.

  • mvn gw:gw processes repository guidance.
  • mvn gw:gw-per-module -Dgw.path=src/site processes each reactor module's site.
  • mvn gw:act -Dgw.act="Rewrite headings for clarity" runs an inline action.
  • mvn gw:act -Dgw.acts=.ghostwriter/acts -Dgw.act=review runs a named action.
  • mvn gw:act-per-module -Dgw.act=review runs an action in reactor context.

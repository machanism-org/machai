GW Maven Plugin

GW Maven Plugin is the project name declared by the module POM. Ghostwriter Maven Plugin is an advanced documentation automation tool for Java projects. It automatically scans, analyzes, and assembles project documentation using embedded guidance tags and AI-powered synthesis. The plugin streamlines the creation and maintenance of high-quality, consistent documentation, ensuring best practices and up-to-date information across all modules.

The plugin applies Ghostwriter workflows to all relevant project files selected by its scan configuration, including source code, documentation, project site content, and other repository files. Guidance remains next to the content it governs, so documentation maintenance can be versioned and executed as part of a Maven build.

Package overview

The org.machanism.machai.gw.maven package provides Maven goals that invoke the Ghostwriter guidance processor or an act processor. Aggregator goals can traverse a multi-module build without requiring a local pom.xml; per-module goals participate in Maven's reactor and use its dependency ordering. The shared base mojo resolves Maven project and session context, scan paths, instructions, exclusions, model selection, settings credentials, optional configuration files, usage reporting, and project class-introspection tools.

The related org.machanism.machai.gw.maven.tools package supplies function tools for Ghostwriter workflows. It scans Maven compile and output classpaths, finds classes by a regular expression applied to their simple names, and exposes structured reflection data including modifiers, superclass, interfaces, fields, constructors, methods, annotations, class locations, source paths, and dependency coordinates.

Execution flow

  1. Maven supplies the current project, session, reactor, and settings context.
  2. The common mojo loads credentials from the configured Maven settings.xml server, or loads the optional Ghostwriter properties file when no server is selected.
  3. The selected goal resolves its model, scan path, instructions, exclusions, and action or guidance request.
  4. A GuidanceProcessor or ActProcessor scans files and applies the configured workflow; class tools are registered when project metadata is available.
  5. Aggregator goals coordinate module traversal themselves, while per-module goals run in the Maven reactor. The aggregator guidance workflow processes submodules before parent modules.

Maven goals

gw:gw
Aggregator guidance-processing goal. It can run without a local POM and coordinates multi-module traversal, including parallel execution.
gw:gw-per-module
Per-module guidance-processing goal. Maven invokes it for reactor modules according to the standard dependency graph.
gw:act
Aggregator act goal. It runs a predefined act or supplied prompt, and interactively requests an act when no value is configured. It can also run without a POM.
gw:act-per-module
Per-module act goal for standard reactor execution. It normally acts from the execution-root project context and supports predefined act locations.

Configuration

Common Maven properties include gw.model for provider/model selection, gw.path for the scan root, gw.instructions for additional instructions, gw.excludes for skipped paths, and gw.config for an optional properties file. The act goals additionally accept gw.act for a prompt or act name and gw.acts for a directory or URL containing act definitions. The genai.serverId property selects a Maven settings.xml server whose username, password, and custom XML properties are forwarded to the provider.

Usage

  • mvn gw:gw — process repository guidance.
  • mvn gw:gw-per-module -Dgw.path=src/site — process each reactor module's site.
  • mvn gw:act -Dgw.act="Rewrite headings for clarity" — run an inline action.
  • mvn gw:act -Dgw.acts=.ghostwriter/acts -Dgw.act=review — run a named action.
  • mvn gw:act-per-module -Dgw.act=review — run an action in reactor context.

Package structure

  • org.machanism.machai.gw.maven: AbstractGWMojo provides shared Maven integration; GWMojo, GWPerModuleMojo, ActMojo, and ActPerModuleMojo implement the four plugin goals.
  • org.machanism.machai.gw.maven.tools: ClassFunctionalTools exposes class lookup and inspection functions, while ClassInfoHolder builds the project class loader and records class-origin metadata.
